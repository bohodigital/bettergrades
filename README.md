# Better Grades

Better Grades is a free academic answer, explanation, calculator, practice, and diagnostic platform. The initial release focuses on calculus and connects every useful answer to the method and practice behind it.

## Product areas

- Searchable answer bank with explicit answer depth and verification state
- Full canonical solution for the integral of sec³x
- Integration-by-parts method guide
- Functional Integration Method Finder
- Ten-question method-selection practice
- Twelve-question calculus-readiness diagnostic
- Twenty-problem timed or untimed Integration Bee
- Auto, light, and dark themes
- Device-local practice progress; no account required

The content model separates problems, public pages, methods, sources, review state, and related resources. Conservative canonicalization helpers flag potential duplicate intent, equivalent variable naming, and overlapping answers for editorial review.
