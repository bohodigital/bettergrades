# BetterGrades Findability Handoff 1 implementation

This release adds one semantic graph over the current registries, deterministic generation/check commands, exact search precedence, role-specific result labels, canonical parent links for critical routes, desktop/mobile destination parity, and privacy-bounded interaction analytics.

The graph currently contains 497 instructional/resource nodes plus 12 explicit non-instructional exclusions. It contains existing public relationships and 2,756 provisional audit-candidate relationships. Public queries filter strictly to `approved` or `existing`.

Copied audit evidence is limited to the named documentation, raw queues, four machine reports, deterministic audit runner/build-reproducibility tooling, and its test. Audit screenshots and bulky temporary CSV/JSON output were not imported.
