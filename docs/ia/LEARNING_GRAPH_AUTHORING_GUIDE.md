# Learning graph authoring guide

Add new substantive content to its existing authoritative registry first. Give it a durable registry ID, canonical path, role, concise title, aliases, concept, and skills. Run `graph:generate`, inspect the node, then run `graph:check`.

To connect an article, add a reviewed explicit relationship. Use `full_version_of` only when one destination is the clear full lesson. Use `practices`, `references`, `visualizes`, or `uses_tool` for their literal learner purpose.

Do not create a relationship from broad course membership, lexical similarity alone, or a desire to distribute link equity. Do not approve more than one primary full-learning destination. Reciprocal links are required only when the learner genuinely needs a return path.

Register former paths and bounded human-authored aliases. Do not create speculative synonym swamps.
