# BetterGrades Branch 1 SEO Architecture Audit

## Outcome

The fresh production-equivalent build contains 988 canonical HTML routes: 974 instructional/indexable mathematical routes in the ownership registry and 14 documented shell/policy exclusions. The rendered redirect map contains 135 one-hop entries.

Every instructional graph node was rendered, self-canonical, and represented in the sitemap. The registry contains one primary target query per mathematical URL. Search Console metrics were unavailable and are explicitly marked UNAVAILABLE.

## Safe remediation

- Preserved all established canonicals. No merge, redirect, or noindex action was added.
- Repositioned compact Algebra surfaces around decision, diagnostic, exception, or error-prevention intent while textbook lessons retain generic instructional ownership.
- Qualified all 64 unit-level Precalculus assessment H1/title surfaces by topic and clarified high-opacity lesson titles without changing lesson URLs.
- Separated the integration-by-parts textbook, recognition guide, and repeated/tabular/cyclic strategy intents.
- Recorded 969 current collision candidates with the published multi-signal score and generated Branch 4 evidence gates.

## Evidence limits

GSC query/page exports, URL Inspection, backlink data, and external rank tracking were not available. Those missing sources block destructive consolidation, not safe title/H1 and internal-intent differentiation.

## Durable artifacts

The machine-readable registry, title ledger, redirect ledger, collision candidates, QA report, and Branch 2/3/4 handoffs live under `data/seo/` and `artifacts/seo-architecture/`. Regenerate with `pnpm seo:architecture`; verify drift with `pnpm seo:architecture:check`.
