# BetterGrades Image and Visual SEO Standard

Instructional diagrams use exact text and vector geometry, not image-generation systems.

Every promoted visual includes a script-free SVG, explicit dimensions, short and long descriptions, numbered written meaning, a responsive PNG, a printable resource or PDF, stable asset URLs, and links to lessons, practice, and glossary concepts. Meaning does not rely on color.

The first set covers secant-to-tangent behavior, derivative rules, open-box optimization, Riemann sums, the Fundamental Theorem, integration by parts, geometric self-similarity, convergence-test selection, radius and interval of convergence, and Taylor approximation.

Only visuals with standalone teaching value receive indexable landing pages or image-sitemap entries.
