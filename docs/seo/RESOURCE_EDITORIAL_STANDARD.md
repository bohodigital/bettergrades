# BetterGrades Resource Editorial Standard

Published resources must teach a coherent skill, not exist to create a URL.

- Worksheets and exams state level, prerequisites, skills, count, time, and calculator assumptions.
- Student editions remain answer-free; separate keys and accessible HTML contain every answer and derivation.
- Worked solutions explain method choice and a common wrong approach.
- Only editorially selected problems receive indexable pages. Random coefficient or seed variants are not published.
- Original glossary entries and anchors remain stable. Only selected high-value terms receive substantial pages.
- Every problem records an independent reviewed verification result in `artifacts/seo/mathematical-verification.json`.

An unresolved mathematical or relationship failure blocks publishing.
