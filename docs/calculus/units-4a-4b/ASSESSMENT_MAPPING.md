# Unit 4 assessment mapping

## Unit 4A

- Lesson checks: 22, one per instructional lesson
- Assessment sets: concept quiz, Practice Exam A, Practice Exam B
- Practice exams: separately routed from their complete answer keys
- Reveal policy: attempt required before worked solutions are returned
- Public payload: prompt, answer type, choices when applicable, hints, difficulty, topics, and skills
- Server payload: canonical answers, accepted variants, worked solutions, and rubrics

Dedicated tests confirm that public artifacts exclude canonical answers, source LaTeX, server-only source paths, worked solution fields, and model responses.
