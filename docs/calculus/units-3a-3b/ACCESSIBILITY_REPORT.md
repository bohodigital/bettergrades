# Accessibility report

## Unit 3A candidate

- Semantic heading order and typed content nodes replace raw source markup.
- Every visual retains visible explanatory copy and an accessible SVG title/description.
- Interactive sliders expose names, values, keyboard arrows, page-step keys, Home, and End.
- Controls are optional enhancements; the static fallback remains available when JavaScript is disabled or enhancement fails.
- Reduced-motion preference does not start animation.
- Visuals use color-independent boundaries and labels.
- Answer reveal controls remain native buttons/details and do not reveal answers before an attempt.
- Responsive Lens blocks, tables, and visual containers are bounded against horizontal overflow.

The automated accessibility and keyboard contracts pass locally. Hosted desktop/mobile, light/dark, keyboard, reduced-motion, and JavaScript-disabled observations are recorded in the unit release report.
