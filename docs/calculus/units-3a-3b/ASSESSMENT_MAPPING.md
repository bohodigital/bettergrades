# Assessment mapping

## Unit 3A boundary

- Quick checks are route-mapped and attempt-gated.
- Cumulative practice receives one server-authorized reveal per supplied exercise.
- Practice Exam A and Practice Exam B are independent assessment sets.
- Each exam has a separately routed, numbered, easy-to-find public answer key.

## Grading policies

- Multiple choice: exact normalized option identity.
- Numeric and rational: bounded deterministic comparison.
- Symbolic: server-only algebraic equivalence at the existing compute boundary.
- Antiderivative: algebraic equivalence plus an explicit arbitrary additive constant where required; `C`, `K`, and an equivalent named constant normalize without accepting a missing constant.
- Definite-integral setup: bounded structural comparison of coefficient, bounds, variable, and integrand. A parse failure returns `uncertain`.
- Reveal: exact unit, route, reveal identifier, and attempt gate.

Canonical answers, model solutions, and private rubrics stay in server-only artifacts and are covered by public-bundle leak tests.
