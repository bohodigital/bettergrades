# Provenance and rights review

## Source declaration

The v3 handoff declares the Unit 2A and Unit 2B instructional composition to be independently written BetterGrades material. Reference textbooks are recorded as references and are not packaged as application assets.

The public page notice accurately states that the composition is declared BetterGrades-original and that owner/editor provenance review is required before public release. This implementation preserves that declaration; it does not convert it into an independent legal guarantee.

## Separation controls

- Source PDFs, reference books, archives, and LaTeX projects remain in durable intake storage.
- Browser artifacts contain no reference-book binaries or source archive paths.
- Server source-path fields are excluded from public indices and public route payloads.
- Visual authoring briefs are converted to renderer-neutral specifications and do not publish source drawing programs.
- Direct adaptations, if identified later, require separate attribution and license handling.
- The 36 cumulative-practice questions retain their normalized v3 route provenance. Their concise answer derivations are BetterGrades-original repository integration work, stored in the server-only answer artifact, and identified there with route-level composition and review status.

## Review outcome

No ambiguous multivariable source was imported. No third-party textbook PDF or extracted chapter is shipped. The remaining limitation is editorial/legal review of the handoff declaration itself; that limitation is visible and documented rather than silently upgraded.
