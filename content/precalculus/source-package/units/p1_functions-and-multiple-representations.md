# Unit P1: Functions and Multiple Representations

**Governing question.** What is a function, and what does each representation allow us to see?

This unit establishes the language of functions across quantities, words, tables, graphs, formulas, and models.

## P1.1. Quantities, variables, and dependency

**Lesson outcome.** Identify the input, output, parameters, and units in a quantitative relationship and explain how the quantities depend on one another.

### Opening

An input is supplied to a relationship, an output is determined by it, and parameters remain fixed for one selected model.

This matters because the rest of Precalculus will repeatedly use quantities, variables, and dependency to decide what a formula means, what a graph can show, and which conclusions remain valid.

### Before you begin

1. Use function notation from P0.
2. Read ordered pairs and interval notation.
3. Attach units to contextual quantities.

### Exact learner exposition

Define every quantity and unit, identify the direction of dependency, and check that terms combined in a formula have compatible units.

The same symbol can play different roles in different models; the context determines whether it is input, output, or parameter.

A symbolic answer is not complete by itself. In this lesson, the same claim must also be readable through quantity dependency map, parameter family graph, or another equivalent representation.

A complete response states what the result means. When the setting is contextual, include units and a meaningful domain. When the result is numerical, distinguish an exact value from an approximation and state the precision used.

### Common mistake

A frequent error is manipulating symbols before defining what they measure.

## P1.2. Relations and functions

**Lesson outcome.** Determine whether a relation is a function by applying the rule that each allowed input has exactly one output.

### Opening

A relation is a function when every allowed input has exactly one output. Several inputs may share an output.

This matters because the rest of Precalculus will repeatedly use relations and functions to decide what a formula means, what a graph can show, and which conclusions remain valid.

### Before you begin

1. Use function notation from P0.
2. Read ordered pairs and interval notation.
3. Attach units to contextual quantities.

### Exact learner exposition

Check repeated inputs in a table, outgoing arrows in a mapping, vertical intersections in a graph, or the rule stated by a context.

## P1.3. Function notation, evaluation, and solving

**Lesson outcome.** Use function notation accurately and distinguish finding an output from finding inputs that produce a chosen output.

### Opening

The notation f(x) names the output of function f at input x; it is not multiplication.

This matters because the rest of Precalculus will repeatedly use function notation, evaluation, and solving to decide what a formula means, what a graph can show, and which conclusions remain valid.

### Before you begin

1. Use function notation from P0.
2. Read ordered pairs and interval notation.
3. Attach units to contextual quantities.

### Exact learner exposition

Substitute the entire input with parentheses or trace the input through a table or graph. For f(x)=k, solve for every preimage.

A function produces at most one output for an allowed input, but a fixed output may have several inputs.

A symbolic answer is not complete by itself. In this lesson, the same claim must also be readable through vertical versus horizontal tracing, substitution grouping, or another equivalent representation.

A complete response states what the result means. When the setting is contextual, include units and a meaningful domain. When the result is numerical, distinguish an exact value from an approximation and state the precision used.
