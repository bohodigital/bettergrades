# Unit P2: Transformations and Function Operations

**Governing question.** How can a familiar function be moved, reflected, scaled, and combined while retaining recognizable structure?

This unit treats familiar functions as reference objects that can be transformed and combined through coordinate mappings.

## P2.2. Coordinate mappings and transformation logic

**Lesson outcome.** Derive graph transformations by tracking how input-output pairs move.

### Opening

A graph transformation is a coordinate map from a point (u,v) on the parent to a point on the transformed graph.

This matters because the rest of Precalculus will repeatedly use coordinate mappings and transformation logic to decide what a formula means, what a graph can show, and which conclusions remain valid.

### Before you begin

1. Recognize the parent function family.
2. Read domain, range, and key points.
3. Use coordinate mappings.

### Exact learner exposition

Outside operations alter v; inside operations determine the new x by solving the inside expression equal to u.

For a f(b(x-h))+k, the map is (u,v) to (h+u/b,av+k).
