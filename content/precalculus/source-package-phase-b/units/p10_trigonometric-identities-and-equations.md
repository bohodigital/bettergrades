# Unit P10: Trigonometric Identities and Equations

This unit treats identities as claims of functional equivalence and equations as claims about selected inputs. Algebraic structure, domain, periodicity, and numerical verification must remain visible throughout. The governing question is: **Which trigonometric expressions represent the same function, and how can periodic equations be solved completely?**

## Unit anchor problem

Two sensors report S1(t)=3sin t+4cos t and S2(t)=5sin(t+phi). Determine phi, prove the expressions are identical, and find every t in [0,2pi) when the output equals 4.

The anchor problem should remain visible throughout the unit. Each lesson contributes one part of the language or method needed to solve it completely, and the unit investigation asks the learner to build a related model independently.

## P10.1. Identities, equations, and proof strategy

**Learning objective.** Distinguish identities from conditional equations and use valid one-sided transformation strategies.

### The problem that opens the lesson

**Opening solution.** Is (1-cos^2 x)/sin x=sin x an identity? State the exact common domain on which the equality is valid.

**Solution.** Begin by identifying the mathematical object and the information that fixes it. If the original statement has a restricted common domain, state it. Following that structure gives **Yes where sin x is nonzero; the left side is undefined at integer multiples of pi.**

**Why this works.** The common domain matters because algebraic simplification can remove a factor that was originally zero or introduce a reciprocal that excludes additional inputs. The calculation and the representation should agree, so a graph, diagram, table, or substitution check should support the same conclusion.

### What this lesson is really about

A trigonometric identity is an equation true for every input in the common domain of both sides. A conditional equation is true only for selected inputs.

Identity verification is a proof task: the goal is to transform one expression through valid equivalences until it matches the other. Substituting sample values can detect false statements but cannot prove an identity over infinitely many inputs.

The point is not merely to reproduce a formula. A learner should be able to identify the quantities or geometric objects involved, explain why the relationship has its stated form, and recognize when the same idea appears in a graph, table, diagram, or model.
